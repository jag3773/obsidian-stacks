# Stacks logo package

The Stacks mark is three equal rounded bars, a stack of sources, with the middle bar pushed furthest out. Its geometry comes from the promo video; its colours are the **Index** palette.

## Files

| File | Use |
|---|---|
| `svg/stacks-logo-horizontal-light.svg` | Default logo on light backgrounds |
| `svg/stacks-logo-horizontal-dark.svg` | Default logo on dark backgrounds |
| `svg/stacks-logo-horizontal-mono-ink.svg` / `-mono-white.svg` | One-colour print, embossing, photos |
| `svg/stacks-logo-stacked-light.svg` / `-dark.svg` | Square-ish spaces: profile headers, title slides |
| `svg/stacks-mark-*.svg` | The mark alone (light, dark, mono-ink, mono-white) |
| `svg/stacks-app-icon-dark.svg` / `-light.svg` | 1024 px rounded-square icon |
| `svg/favicon.svg` | Browser tab icon (dark tile) |
| `svg/stacks-social-card-light.svg` / `-dark.svg` | 1280 × 640 GitHub social preview |
| `png/` | Rendered PNGs of all of the above, plus `favicon-16/32/48/180/512.png` |

“Light” and “dark” name the **background** the file is made for.

The wordmark is outlined, so no font needs to be installed. It is set in Space Grotesk Bold (SIL Open Font License) with −0.02 em tracking.

## Colours

| Name | Hex | In the logo |
|---|---|---|
| Ink | `#0F1419` | Top bar and wordmark on light; tile on dark icon |
| Signal | `#FF5A1F` | Middle bar, always |
| Slate | `#5A6472` | Bottom bar on light |
| Paper | `#F4F5F7` | Top bar and wordmark on dark |
| Slate light | `#8B95A3` | Bottom bar on dark |

## Using it

- **Clear space:** keep at least half the mark’s height clear on every side.
- **Minimum size:** the mark at 16 px tall; the horizontal logo at 96 px wide.
- **Construction:** bars are 100 × 26 with 7 radius and 8 gap; offsets 0 / 22 / 10. In the lockup the mark is 1.3 × the wordmark’s cap height, centred on it, with a gap of 0.32 × the mark’s height.
- **Don’t** recolour the middle bar, change the bar offsets, rotate the mark, add effects, or set the wordmark in another font.

## Rebuilding

The SVGs are generated by [`brand/tools/build_logo.py`](../tools/build_logo.py), which outlines Space Grotesk at weight 700 with fontTools. Its docstring says where to get the font and how the PNGs were rendered.
